# Local Setup Runbook

## Prerequisites

Development is configured for a single development laptop running Windows 11.

- **JDK**: Java 17+ (Tested with Eclipse Temurin / OpenJDK 17)
- **Node.js**: v20+ or v24+ & npm
- **Flutter SDK**: 3.24+ (Tested with Flutter 3.38.5)
- **Python**: 3.10+ (Tested with Python 3.14.0)
- **Docker & Docker Compose**: Docker Desktop with Linux containers enabled

| Service | Port | Description |

## Step-by-Step Launch Sequence

### 1. Environment Variables Configuration
Clone the repository and copy the environment configuration:
```powershell
cp .env.example .env
```

### 2. Start Core Infrastructure (Docker Compose)
Start PostgreSQL, Redis, and RabbitMQ:
```powershell
docker compose up -d
```
Verify containers are healthy:
```powershell
docker compose ps
```

### 3. Start Spring Boot Modular Monolith
In a new PowerShell terminal:
```powershell
cd backend\spring-boot-application
.\mvnw.cmd spring-boot:run
```
Flyway migrations `V1` through `V8` will run automatically on startup.
- Swagger UI will be available at: [http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)
- Health check: [http://localhost:8080/api/v1/health](http://localhost:8080/api/v1/health)

### 4. Start Customer Flutter Mobile Application
In a new PowerShell terminal:
```powershell
cd apps\customer-app
flutter pub get
flutter run -d chrome
# OR for native Windows desktop:
# flutter run -d windows
```
*Note: For Android Emulator, the Dio HTTP client connects to `http://10.0.2.2:8080/api/v1`. For Windows desktop or web, it connects to `http://localhost:8080/api/v1`.*


### 5. Start Farmer Flutter Mobile Application
In a separate PowerShell terminal:
```powershell
cd apps\farmer-app
flutter pub get
flutter run
```

### 6. Start Admin Panel (React + TypeScript + Vite)
In a new PowerShell terminal:
```powershell
cd apps\admin-panel
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 7. Start AI Service (Optional in Phase 0)
In a new PowerShell terminal:
```powershell
cd ai-service
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
Health endpoint: [http://localhost:8000/health](http://localhost:8000/health)
